# C++ Data Structures & Logic Projects

This repository contains my C++ programming assignments and core Data Structure (DSA) implementations.

## Current Project: Circular Queue (Linked List)
I have recently uploaded a **Circular Queue** implementation developed using a Linked List. Unlike a standard queue, this structure maintains a circular connection between nodes.

### Key Features:
* **Circular Logic:** The `next` pointer of the tail node always points back to the head node.
* **Dynamic Memory:** Utilizes linked lists for efficient memory usage without a fixed size limit.
* **Operations:** Includes core functionalities such as `pushback`, `popfront`, `peek`, and `rear`.
